# Character Data

Each character should eventually have structured metadata for worksheet generation.

Suggested fields:

- `char`
- `type`
- `label`
- `image`
- `ruling`
- `strokes`

Example:

```json
{
  "char": "A",
  "type": "uppercase",
  "label": "A is for Apple",
  "image": "apple",
  "ruling": "uppercase",
  "strokes": []
}
```
